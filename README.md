# Multiplication Trainer
This is an interactive trainer for learning multiplication.
It was made to help primary school students understand multiplication theme and practise with a smart check system and progress saving.
## Demo
https://jsprogrammer-creator.github.io/multiplication-trainer/
## Features
- Multiplication table generator
- Theory with tasks
- Practise with examples repetitions avoidance *
- Dark and light themes (user's theme choice is saved via localStorage)
- Progress saving (localStorage)
## Technologies
HTML, CSS, JS, Adaptive, localStorage

* - by repetitions avoidance, I mean that in practise mode, repeated pairs are avoided (e.g., 2 x 3 and 3 x 2) to ensure thorough learning.
